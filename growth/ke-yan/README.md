# 科研入门

>对于刚进入大学的新生来说，“科研”可能是一个既熟悉又陌生的词。

实际上，科研并不是研究生和博士生的专属活动。

下面主要面向计算机专业本科新生，从科研的基本概念、方向选择、开展过程以及科研成果的价值四个方面进行介绍。

## 一、什么是科研？
简单来说，科研的核心是提出问题、研究问题，并通过可靠的方法验证自己的答案。

科研与平时完成课程作业有所不同。课程作业通常有明确的知识范围和相对成熟的解决方法，而**科研面对的问题往往没有现成的标准答案**，需要研究者自己寻找突破口。

以计算机专业为例：

- 人工智能： 如何让大语言模型在更少的计算资源下完成高质量推理？
- 计算机视觉： 如何让自动驾驶系统在大雾、夜晚等复杂环境下准确识别行人？
- 网络安全： 如何发现软件系统中尚未被识别的安全漏洞？
- 计算机系统： 如何优化数据库，使其在处理海量数据时仍然保持较高的运行效率？
- 软件工程： 如何利用人工智能辅助检测代码缺陷，提高软件开发效率？

这些问题往往无法仅仅依靠课堂上学到的知识直接解决，需要查阅已有研究、提出新的方法，并通过实验验证其有效性。

### 科研和普通项目开发有什么区别？

以开发一个图像识别系统为例：

| 对比维度 | 普通项目开发         | 科学研究             |
| ---- | -------------- | ---------------- |
| 核心目标 | 实现一个能够使用的系统    | 解决尚未得到充分解决的问题    |
| 主要工作 | 编写程序、实现功能、测试系统 | 分析已有方法、提出改进、开展实验 |
| 评价标准 | 功能是否完整，系统是否稳定  | 方法是否具有创新性，结论是否可靠 |
| 最终成果 | 软件、网站、应用程序等    | 论文、算法、实验发现、研究系统等 |

两者并不是相互独立的。一个优秀的软件项目可以成为科研的实验平台，而科研中提出的新算法也可以应用到真实的软件产品中。

需要注意的是，**使用现有技术完成一个项目，并不自动等于完成了一项科研工作**。科研通常还需要明确的研究问题、相对已有工作的创新或新发现，以及能够支持结论的证据。

## 二、科研方向重要吗？
对于计算机专业来说，常见的科研方向包括人工智能、机器学习、计算机视觉、自然语言处理、网络安全、计算机网络、数据库、操作系统、软件工程、人机交互等。

**科研方向很重要**，对于你后续的职业发展，升学和就业都有很深远的影响，**千万不要因为门槛低，选择一个发不出论文，自己也不感兴趣的科研方向**。

### 1. 科研方向决定了你主要学习什么

不同方向需要的知识和技能存在明显差异。

| 科研方向      | 主要研究内容          | 常见知识基础           |
| --------- | --------------- | ---------------- |
| 人工智能与机器学习 | 模型训练、优化与智能决策    | Python、线性代数、概率论  |
| 计算机视觉     | 图像识别、目标检测、三维重建  | 深度学习、图像处理        |
| 自然语言处理    | 文本理解、大语言模型、机器翻译 | Python、机器学习、语言模型 |
| 网络安全      | 漏洞检测、密码学、系统安全   | 计算机网络、操作系统、编程    |
| 计算机系统     | 操作系统、数据库、分布式系统  | C/C++、数据结构、系统原理  |
| 软件工程      | 程序分析、软件测试、开发工具  | 编程、软件设计、程序分析     |
| 人机交互      | 人机界面、交互体验、智能交互  | 编程、交互设计、用户研究     |

### 2. 科研方向会影响未来的发展机会

不同科研方向与升学、就业之间存在一定关联。

例如，人工智能研究经历可能与机器学习算法岗位相关，网络安全研究经历可能与安全研究岗位相关，计算机系统研究则可能与数据库、基础架构和高性能计算等领域相关。

### 3. 新生应该如何选择科研方向？

建议采用先广泛了解，再逐步深入的方式。

大一阶段可以优先学习编程、数学和计算机基础知识，**了解不同方向的研究内容**。

大二阶段正式确定自己的科研方向，后续可以不断修正和调整。

## 三、如何开展科研？

对于没有科研经验的新生来说，科研并不是一开始就要独立提出全新的理论，更常见的入门方式是**跟随导师或高年级同学（博士生为主）**，从基础知识学习、论文阅读和实验复现开始，逐步参与完整的研究过程。

### 1. 科研的一般流程

第一步：确定研究方向与问题

明确要研究什么，以及为什么值得研究

第二步：阅读相关文献

了解前人做了什么、有哪些不足

第三步：复现已有方法

运行开源代码、验证论文实验结果

第四步：提出并实现研究方案

设计改进方法、算法或者实验

第五步：实验验证与分析

与现有方法比较，检验结果是否可靠

第六步：整理并展示研究成果

形成论文、技术报告、代码或研究系统

科研并不总是严格按照上述顺序进行。实验结果不理想时，可能需要重新阅读文献、修改假设或调整研究方案。反复尝试是科研过程中的正常现象。

### 2. 本科生有哪些参与科研的途径？

第一种：加入导师的课题组或实验室。

这是本科生接触科研的常见方式。可以通过**学院官网**了解教师的研究方向，主动联系研究方向感兴趣的老师。

加入课题组之后，通常会先完成一些基础任务，如阅读论文、配置实验环境、复现代码、处理数据等，再逐步参与研究方案设计。

第二种：参加大学生创新创业训练计划等科研项目。

部分大创项目属于创新训练或研究性项目，同学们可以在指导教师帮助下确定课题，完成研究方案、实验验证和项目总结。

这类项目通常具有一定的时间周期，适合希望系统体验研究过程的本科生。

## 四、计算机专业的科研成果是什么？
计算机专业的科研成果一般指的是**已发表的**论文，或者是正在投稿过程中的高质量论文。

### 什么是学术论文？什么是顶会？
与部分其他学科相比，计算机领域的高水平学术会议具有重要地位。不同方向通常有各自具有代表性的会议，例如：

| 研究领域   | 代表性会议                    |
| ------ | ------------------------ |
| 机器学习   | NeurIPS、ICML、ICLR        |
| 计算机视觉  | CVPR、ICCV、ECCV           |
| 自然语言处理 | ACL、EMNLP                |
| 数据库    | SIGMOD、VLDB              |
| 计算机系统  | OSDI、SOSP                |
| 网络安全   | IEEE S&P、USENIX Security |
| 软件工程   | ICSE、FSE                 |

这些都是计算机领域受到关注的学术会议，具体会议定位和评价方式需要结合研究方向判断，可以参考 CSRankings 的计算机学科分类。


另外，同学们可能经常听到 SCI、EI、CCF A/B/C 等概念。它们并不是完全相同的评价体系：

- SCI、EI： 主要是学术文献的**检索或索引**体系。
- CCF A/B/C： 是中国计算机学会对相关国际学术会议和期刊作出的**分级推荐**，具体以现行目录为准。

## 五、科研成果有什么用？

科研成果的价值主要体现在升学和就业两个方面，但不同发展路径对科研经历的重视程度不同。

### 1. 升学：科研经历可以帮助展示研究潜力
部分高校在推免选拔、夏令营或研究生复试中，**会考察学生的科研经历、创新能力**和专业知识掌握情况。

在海外升学方面：

**申请研究型硕士或博士**项目时，科研经历可以用于证明申请者具有一定研究能力，尤其是能够独立分析问题、设计实验和解释结果。

### 2. 就业：科研经历如何转化为求职优势？

对于算法工程师、AI 研究员等岗位，与机器学习、自然语言处理、计算机视觉等相关的科研经历，可能有助于展示模型训练、算法改进、实验分析和前沿技术理解能力。

部分研究型岗位对硕博**学历**和**研究成果**有较高要求。
