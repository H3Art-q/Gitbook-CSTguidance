# 竞赛

> **内容性质：** 年级课程导读与个人经验
>
> **适用范围：** 暨南大学计算机科学与技术专业学生。
>
> **最后核验：** 2026-10-08
>
> **作者：** [MayL](https://github.com/sekirooox)

## 竞赛入门

>学科竞赛是将课堂知识运用到实际问题中的重要途径，~~**也是重要的保研和综测加分手段**🤣~~。

有些竞赛侧重数学分析与编程，有些强调创意与项目实践，还有些注重语言能力、工程设计和团队协作。


## 数学建模类竞赛

>代表赛事：全国大学生数学建模竞赛、美国大学生数学建模竞赛（MCM/ICM）、全国大学生统计建模大赛

数学建模类竞赛的核心，是利用数学、统计学和计算机技术解决现实生活中的复杂问题。

与传统数学考试不同，数学建模题目**通常没有唯一的标准答案**。

例如，如何优化城市交通、预测新能源汽车销量、设计最佳物流配送路线等，都可以成为数学建模研究的问题。

主要工作： 参赛队员需要**理解题目、提出合理假设、建立数学模型**，利用 Python、MATLAB 等工具进行数据处理、计算与仿真，**最后撰写论文**，说明解决问题的思路、过程与结果。

一般开展方式：

- **数学建模国赛 (简称国赛，含金量最高)**： 通常由3名学生组成团队，在约3天的时间内完成赛题分析、建模求解和论文提交，强调限时团队协作。

- **美国大学生数学建模竞赛 (简称美赛，含金量次之，但是属于国际类比赛)**： 包括 MCM 和 ICM，通常由不超过3名学生组队，在连续约4天内完成开放性问题研究，并提交英文论文。对英文科技写作有一定要求。

- **统计建模大赛 (可以用于保研和综测加分)**： 更侧重真实数据的收集、清洗、统计分析和结果解释，通常围绕特定主题开展研究，形成统计分析论文，部分晋级队伍还需要进行现场答辩。

新生入门建议： 可以先学习 Python、Excel、基础统计学和数学建模方法，同时练习阅读优秀论文、制作数据可视化图表。

## 二、算法竞赛类

>代表赛事：ICPC、CCPC、蓝桥杯，以及采用 ACM、OI 等赛制的程序设计竞赛

算法竞赛主要考察选手的**编程能力、逻辑思维和算法设计**能力。

参赛者需要使用 C++、Java、Python 等编程语言，通过编写程序解决指定的计算问题。例如，寻找地图中的最短路径、优化任务调度、分析字符串，或者在复杂条件下求出最优解。

一般开展方式：

算法竞赛中经常提到的 ACM 和 OI，通常是指两种不同的评测与排名模式，而 ICPC、CCPC 和蓝桥杯则是具体的赛事。

- ACM/ICPC 类赛制： 通常按照通过的题目数量排名，在解题数量相同时比较罚时，**提交后有即时反馈**。错误提交可能增加罚时，强调解题速度和准确率。
- OI 类赛制： 通常采用**按测试点或子任务计分**的方式，一道题即使没有完全解决，**也可能获得部分分数**，强调尽可能取得更高总分。**但提交后没有任何反馈**，不知道测试点的通过情况。
- ICPC、CCPC **(保研认可，极高含金量的竞赛)**： 具有代表性的大学生程序设计竞赛，通常采用3人组队的形式，在限定时间内合作完成多道算法题，具有较强的竞技性。
- 蓝桥杯： 包含软件及其他相关赛道，其中软件类竞赛通常以个人参赛为主，根据组别和项目进行编程解题，适合通过系统训练逐步积累经验。

新生入门建议： 尽早加入校队，开展ACM相关练习。**非校队者不建议专门练习算法竞赛**。

## 三、创新创业类竞赛

>代表项目：中国国际大学生创新大赛（原“互联网+”大学生创新创业大赛）、大学生创新创业训练计划（大创）

创新创业类活动主要关注如何将创意、技术或科研成果转化为具有实际价值的项目。

主要工作： 参赛团队**需要寻找真实需求**，确定项目主题，开展市场调研或技术研究，**设计解决方案，制作产品原型或形成研究成果**，并通过项目计划书、展示 PPT 和答辩介绍项目价值。

一般开展方式：

- **大学生创新创业训练计划（大创，保研和综测加分很多）**： 一般以团队项目形式开展，在指导教师帮助下完成项目申报、立项、研究开发、中期检查和结题验收，周期通常较长，重视研究过程和实际成果。
- **中国国际大学生创新大赛（保研和综测加分很多）**： 以创新创业项目为核心，常见流程包括项目培育、报名、材料评审、项目展示和答辩。国内项目主要通过校级初赛、省级复赛和全国总决赛等阶段进行选拔。

新生入门建议： 可以**优先关注学校科研实验室、创新创业社团和教师课题组**，尝试参与已有项目，从资料搜集、市场调研、产品设计、程序开发或 PPT 制作等基础工作开始，逐步了解项目从构想到落地的全过程。

## 四、英语类竞赛

代表赛事：全国大学生英语竞赛（NECCS）、大学生英语演讲比赛、英语写作与阅读竞赛等

英语类竞赛主要考察参赛者的英语基础知识、语言理解能力和实际表达能力。

一般开展方式：

- **全国大学生英语竞赛 (可以用于保研或者综测加分)**： 通常以个人笔试为主，包含听力与笔答内容，设置初赛和决赛等阶段。赛事按照不同参赛人群划分 A、B、C、D 四类，其中非英语专业普通本科生通常参加 C 类竞赛。
- 英语演讲类竞赛： 通常经过报名、初赛选拔、主题演讲、即兴演讲及问答等环节，考察英语口语、逻辑表达和临场反应能力。
- 英语写作与阅读类竞赛： 主要通过限时写作、阅读理解等方式，考察选手的信息提取、语言组织和英文表达能力。

## 五、机电与机器人类竞赛

>代表赛事：RoboMaster 机甲大师高校系列赛、全国大学生机器人大赛相关赛项等

机电与机器人类竞赛主要考察学生的机械设计、电子技术、自动控制、嵌入式开发和系统集成能力。

一般开展方式：

以 **RoboMaster 机甲大师高校系列赛（保研认可，极高含金量的竞赛）为例**，参赛者需要组建跨专业战队，根据比赛规则自主研发不同类型的机器人，在指定场地内完成竞技对抗任务。

一支完整的机器人战队通常包含机械、电控、算法、视觉、嵌入式和运营宣传等不同方向的成员。

**比赛准备周期往往较长**，一般需要经历方案设计、硬件制作、软件开发、单机测试、整机联调、模拟对抗和正式比赛等阶段。RoboMaster 部分赛事还设有研发进度考核与技术评审环节。

新生入门建议： 对机械方向感兴趣的同学可以学习 CAD、SolidWorks 等三维建模工具；对电子与控制方向感兴趣的同学可以学习电路基础、单片机和 STM32；对软件与算法方向感兴趣的同学则可以学习 C/C++、Python、OpenCV 等技术。


## 六、五大类竞赛特点对比

| 竞赛类型  | 核心工作            | 常见参与形式  | 主要能力        |
| ----- | --------------- | ------- | ----------- |
| 数学建模类 | 建立模型、分析数据、撰写论文  | 小型团队    | 数学、编程、论文写作  |
| 算法竞赛类 | 设计算法、编写代码、解决问题  | 个人或3人团队 | 编程、算法、逻辑思维  |
| 创新创业类 | 项目研究、产品开发、展示答辩  | 项目团队    | 创新、调研、项目管理  |
| 英语类   | 语言测试、写作、演讲      | 以个人为主   | 听说读写译       |
| 机电类   | 机器人研发、硬件制作、整机调试 | 多人技术团队  | 机械、电子、控制、编程 |
